# Soul Ledger (web)

Versión web de Soul Ledger, una herramienta de fans para Deadlock: orden de compra según tu lobby, meta de héroes y reloj de partida.

- App: https://brasa-labs-app.github.io/soulledger/
- Política de privacidad: https://brasa-labs-app.github.io/soulledger/privacy.html
- Datos: [deadlock-api.com](https://deadlock-api.com)

Soul Ledger es un proyecto de fans, sin relación con Valve Corporation ni respaldado por ella. Deadlock y su arte son marcas y propiedad de Valve.
